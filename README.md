# sentinel-akim

**sentinel-akim** é um CLI em Go para monitoramento e diagnóstico de sistemas operacionais.  
Ele fornece métricas de CPU, memória, processos, Health Score e diagnósticos inteligentes, permitindo identificar gargalos e problemas de desempenho de forma rápida.

---

## 🔹 Funcionalidades

- **Status do sistema:** CPU, memória e Health Score
- **Diagnósticos inteligentes:** alertas sobre alto consumo com recomendações
- **Top processos:** visualização dos processos que mais consomem CPU ou memória
- **Cross-platform:** funciona em Windows, Linux e macOS
- **CLI profissional:** comandos intuitivos e fáceis de usar
